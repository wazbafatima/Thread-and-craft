# Thread and Craft 🧵✨

A high-end, immersive fashion e-commerce platform built to deliver a cinematic shopping experience. Designed with a minimalist aesthetic and cutting-edge web technologies to make browsing and buying clothes feel premium.

## 🚀 Tech Stack
*   **Frontend:** React, Vite, Tailwind CSS
*   **Backend:** Node.js, Express.js
*   **Database:** MongoDB (Mongoose)
*   **Animations & 3D:** GSAP (ScrollTrigger), Lenis (Smooth Scroll), Framer Motion, React Three Fiber (R3F)

## ✨ Key Features
*   **Immersive UI:** Buttery smooth scrolling with Lenis and scroll-driven GSAP animations.
*   **Interactive 3D:** 3D product showcases using React Three Fiber.
*   **Admin Dashboard:** A fully functional admin panel to manage products, inventory, and orders.
*   **Secure Payments:** Integrated Stripe/Razorpay payment gateways.
*   **Responsive Design:** Optimized for a flawless experience across all devices.

## 🛠️ Local Setup
1. Clone the repository
2. Setup `.env` in the `server` folder
3. Run `npm install` in both `client` and `server`
4. Start backend: `npm start` (in server)
5. Start frontend: `npm run dev` (in client)
